# Implementation report

Source specification: `Quantum_Entanglement_Robustness_Project_Documentation.docx`, version 1.0, October 2026.

The project predicts whether bipartite entanglement survives loss of a subsystem. GHZ and W are physical reference families. Family names, density matrices, negativity, and noise metadata are excluded from classifier inputs.

## Expected physics, not executed ML results

An ideal GHZ reduced state is `diag(1/2, 0, 0, 1/2)` and separable. An ideal W reduced state is a one-third vacuum component plus a two-thirds Bell component, with negativity `(√5−1)/6`. Local rotations preserve these negativity values. Losing the spectator of a biseparable Bell state preserves negativity 1/2; losing a Bell-pair member destroys it.

The white-noise mixture gives reduced W negativity `max(0, (1-p)(√5−1)/6 - p/4)`. A separate physics sweep spans p ∈ [0, 1]. Classification uses the five configured levels by default.

## Design decisions

Higher observable budgets reuse a maximum of four feature wires through sequential encoding chunks. This bounds statevector size and makes the full study practical. The four-observable case follows the document's Hadamard/RY/CNOT example. A final common entangler cancels in fidelity for a single chunk; the kernel is an alternative representation and provides no assumed quantum advantage.

Dataset rows are noise variants of independent base states, with a fixed lost qubit per base. Group splits prevent the same physical base from appearing in multiple partitions. Balancing happens at clean-label generation; at higher noise, labels may transition and noisy datasets may become imbalanced. Default levels remain below the ideal W separability boundary.

Validation F1 chooses hyperparameters; each test set remains untouched by fitting and tuning. All seeds and circuit settings are configurable. Exact simulator state overlaps are computed with NumPy from PennyLane circuit outputs, rather than scheduling an expensive compute-uncompute circuit for each pair.

## Execution boundary

The requested primary environment is `qisk`. Dataset generation, classical training, quantum-kernel execution, and measurement/noise experiments are intentionally deferred. Consequently, saved experimental metrics, fitted models, and empirical result figures do not yet exist. The source and presentation outline are complete; a report with actual results is generated by an explicit full run.

Optional generic-state sampling is provided. A dedicated held-out generic-state generalization study is outside the required implementation and is not claimed here.
